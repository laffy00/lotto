# 🎨 ORYNE 다빈치 로또 분석 시스템 v1.0 사용 매뉴얼

## 📋 프로그램 소개
**DA VINCI'S CIPHER: Quantum Lotto Decoder v1.0**은 ORYNE에서 개발한 전문 로또 분석 프로그램입니다.

## 🚀 주요 기능

### 1. 황금비 조합 생성
- 5가지 수학적 알고리즘으로 예측 번호 생성
- 피보나치, 통계, 기하학, 양자물리학, 대통일 이론 적용
- 매회 다른 동적 결과 생성

### 2. 최신 당첨번호 확인
- 실시간 로또 API 연동
- 과거 예측과 실제 당첨번호 매치 분석
- 당첨 등수 자동 계산

### 3. 데이터 갱신
- 전체 로또 데이터 동기화
- 병렬 다운로드로 15배 속도 향상
- 스마트 캐싱으로 효율성 극대화

### 4. 프로그램 정보
- ORYNE 회사 정보
- 법적 고지사항
- 연락처 및 버전 정보

## 📖 사용 방법

### 첫 실행
1. 프로그램 실행 시 자동으로 로또 데이터 다운로드
2. 초기 로딩 완료까지 2-3분 소요
3. 이후 실행은 빠른 속도로 시작

### 예측 번호 생성
1. "황금비 조합 생성" 버튼 클릭
2. 5개 세트의 예측 번호 확인
3. 각 세트별 수학적 설명 참고
4. 예측 데이터 자동 저장

### 당첨 확인
1. "최신 당첨번호 확인" 버튼 클릭
2. 실제 당첨번호와 과거 예측 비교
3. 매치 개수 및 당첨 등수 확인

## ⚠️ 중요 사항

- **개인 사용 전용** (상업적 이용 금지)
