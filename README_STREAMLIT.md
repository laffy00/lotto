## 🚀 실행 방법

### 1. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행

```bash
streamlit run streamlit_app.py
```

### 3. 브라우저에서 확인

자동으로 브라우저가 열리며, 일반적으로 `http://localhost:8501`에서 접속 가능합니다.

## ✨ 주요 기능

### 1️⃣ 실시간 데이터 수집
- 동행복권 공식 API에서 최신 로또 데이터 자동 수집
- 캐시 시스템으로 빠른 로딩
- 데이터 갱신 버튼으로 수동 업데이트 가능

### 2️⃣ 5가지 천재적 알고리즘
1. **세트1: 황금 비율의 서명** - 레오나르도 다빈치의 피보나치 수열
2. **세트2: 우주 평균 회귀의 법칙** - 통계적 평균회귀 이론
3. **세트3: 피에르 드 페르마의 확률론** - 기댓값과 조합론
4. **세트4: 콜모고로프의 공리적 확률론** - 측도론과 엔트로피
5. **세트5: 블레즈 파스칼의 도박 문제 해결** - 공정성과 쿨다운 패널티

### 3️⃣ 시각적 UI
- 구간별 색상 구분 (저/중/고 번호)
- 반응형 레이아웃
- 인터랙티브 차트 및 그래프

### 4️⃣ 과거 예측 매치 분석
- 생성된 예측과 실제 당첨번호 비교
- 등수별 자동 판정 (1등~5등)
- 최고 성과 세트 자동 표시

## 📂 파일 구조

```
lotto/
├── streamlit_app.py          # Streamlit 메인 애플리케이션
├── genius_lotto.py           # 기존 Tkinter 버전 (레거시)
├── requirements.txt          # 필요한 패키지 목록
├── lotto_cache.json         # 로또 데이터 캐시 (자동 생성)
├── lotto_predictions.json   # 예측 데이터 저장 (자동 생성)
└── README_STREAMLIT.md      # 이 파일
```

## 🎯 사용 방법

### 번호 생성
1. 사이드바에서 "🔄 데이터 갱신" 버튼 클릭 (선택사항)
2. 메인 화면에서 "🎯 천재적 번호 생성" 버튼 클릭
3. 5가지 세트의 번호와 상세 설명 확인

### 과거 예측 분석
1. 하단의 "🔍 과거 예측 매치 분석" 섹션으로 스크롤
2. 드롭다운에서 분석할 회차 선택
3. "🔍 매치 분석 실행" 버튼 클릭
4. 각 세트별 매치 결과 및 당첨 등수 확인

## 🆚 Tkinter vs Streamlit

| 기능 | Tkinter 버전 | Streamlit 버전 |
|------|--------------|----------------|
| 실행 방법 | 로컬 앱 실행 | 브라우저 접속 |
| 설치 | 단독 실행 파일 | Python + Streamlit |
| UI 업데이트 | 수동 | 자동 반응형 |
| 배포 | 어려움 | 쉬움 (클라우드) |
| 반응 속도 | 빠름 | 보통 |
